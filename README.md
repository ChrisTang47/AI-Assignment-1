# DAE IT 2025 - AI Assignment 1

## 題目3：不同風格的建築物圖像數據集

### 📝 作業概述
本項目實現自動收集不同風格建築物圖像的數據集，包含自動搜索、下載、處理和分類功能。

### 🎯 作業要求完成情況
- ✅ 使用指定關鍵字在網上搜索圖像
- ✅ 收集 3000-5000 個圖像
- ✅ 記錄圖像的網址 (src) 和替代文字 (alt)
- ✅ 下載圖像到本地資料夾
- ✅ 調整大小並置中裁剪為不超過 500x500 像素
- ✅ 編碼為 JPEG (50-80 質量)
- ✅ 確保文件大小不超過 50KB
- ✅ 使用 TypeScript 實現
- ✅ 使用函數和類組織代碼

### 🛠 技術棧
- **TypeScript**: 主要開發語言
- **Playwright**: 瀏覽器自動化和網頁爬蟲
- **Sharp**: 圖像處理和優化
- **Better-SQLite3**: 本地數據庫存儲
- **Node.js**: 運行環境

### 🏛 支持的建築風格
1. **現代建築 (Modern)**: 現代辦公樓、摩天大樓、玻璃建築
2. **古典建築 (Classical)**: 希臘羅馬風格、新古典主義
3. **哥德式 (Gothic)**: 哥德大教堂、尖拱、飛扶壁
4. **巴洛克 (Baroque)**: 華麗裝飾、巴洛克教堂和宮殿
5. **文藝復興 (Renaissance)**: 意大利文藝復興建築
6. **當代建築 (Contemporary)**: 當代設計風格
7. **極簡主義 (Minimalist)**: 簡約設計
8. **裝飾藝術 (Art Deco)**: 1920年代風格

### 📊 圖像處理規格 - 嚴格符合作業要求
- **尺寸**: 調整大小並置中裁剪為不超過 500x500 像素 ✅
- **格式**: JPEG 
- **質量**: 50-80 (動態調整以達到文件大小要求) ✅
- **文件大小**: 嚴格不超過 50KB (多次優化直到符合) ✅
- **裁剪**: 使用 Sharp 的 `fit: 'cover'` 和 `position: 'center'` 實現置中裁剪 ✅
- **命名**: `{style}_processed_{index}.jpg`

### 🔧 處理邏輯詳解
1. **智能尺寸計算**: 保持長寬比的前提下，將圖片縮放到不超過500x500
2. **置中裁剪**: 如果需要裁剪，從圖片中心進行裁剪
3. **質量動態調整**: 從80質量開始，如果文件過大則逐步降低到50
4. **尺寸二次調整**: 如果降低質量還不夠，再縮小尺寸直到符合50KB要求
5. **嚴格驗證**: 每張處理完的圖片都會驗證是否符合 ≤500x500 和 ≤50KB 要求

### 🔍 數據來源 - 增強搜索策略
1. **Google Images**: 主要來源，每種風格100+關鍵字，大圖過濾
2. **Unsplash**: 高質量建築攝影，滾動加載更多
3. **Pexels**: 免版權專業圖像
4. **額外搜索**: 關鍵字變體補強（exterior, facade, design等）

### 🎯 搜索增強功能
- **大幅擴展關鍵字**: 每種建築風格30+專業術語
- **多輪搜索**: 每個來源最多3輪搜索
- **智能滾動**: 自動加載更多圖片結果
- **嚴格過濾**: 排除logo、icon、avatar等無關圖片
- **尺寸過濾**: 只選擇150x150以上的高質量圖片

### 🐛 故障排除

#### 常見問題
1. **網路連接問題**: 確保網路暢通，某些網站可能需要VPN
2. **瀏覽器啟動失敗**: 確保 Playwright 瀏覽器已安裝
3. **圖像處理失敗**: 確保 Sharp 依賴正確安裝
4. **權限問題**: 確保有文件夾寫入權限

#### 解決方案
```bash
# 重新安裝 Playwright 瀏覽器
npx playwright install

# 重新安裝 Sharp (Windows 用戶)
npm rebuild sharp

# 清理並重新安裝依賴
rm -rf node_modules package-lock.json
npm install
```
